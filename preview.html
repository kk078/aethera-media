Week 4, Tue: Denial Code CO-4 (Inconsistent Modifier)
Denial Code CO-4: When Modifiers Backfire 👇 CO-4 indicates: "The procedure code is inconsistent with the modifier used or a required modifier is missing." It is one of the most frustrating rejections because clearinghouses often miss it, and payers bounce it straight back. The 3 most common modifier mistakes causing CO-4: 1. Attaching Modifier 25 to the Wrong Code: Modifier 25 belongs exclusively on the Evaluation & Management code (99202–99215). Commercial payers like UnitedHealthcare and Aetna frequently reject -50 and demand two line items: • Line 1: CPT with -RT • Line 2: CPT with -LT 3. Anatomical Modifiers on Non-Anatomical Procedures: Appending -E1/-E2 (eyelids) or -F1/-F2 (fingers) to general evaluation codes. Payer modifier preferences differ wildly.
